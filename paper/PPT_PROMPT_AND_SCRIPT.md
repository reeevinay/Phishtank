## Part 2: Presenter Speaker Script (Viva / Defense Ready)

- **Slide 1 (30s)**: "Good morning. Today I'm presenting **PhishTank-NS**, my major engineering capstone and IEEE research project—an uncertainty-aware neuro-symbolic email defense platform built to stop adversarial and polymorphic phishing at cloud scale."
- **Slide 2 (45s)**: "Traditional email gateways rely on static rules like SPF/DKIM or domain blocklists, which fail completely on zero-payload BEC or compromised legitimate accounts. On the other hand, pure AI/LLM scanners are easily fooled by hidden HTML text, Unicode homoglyphs, and prompt injections—and they give uncalibrated confidence scores."
- **Slide 3 (45s)**: "Here is a concrete example of an adversarial attack. The victim only sees the urgent password reset line. Meanwhile, a `display:none` div injects benign newsletter text and a prompt-injection override, while Cyrillic lookalikes break subword tokenizers."
- **Slide 4 (60s)**: "To solve this at scale, PhishTank-NS uses a decoupled polyglot microservices architecture: a React SOC UI and Manifest V3 browser extension talk to a stateless Node.js API Gateway, which streams `.eml` files and enqueues jobs into Redis/BullMQ workers. Workers call our Python FastAPI ML engine and persist embeddings and provenance graphs in PostgreSQL 16 with `pgvector`."
- **Slide 5 (45s)**: "Our first research contribution is visibility-aware de-obfuscation. Before the ML model ever sees an email, we strip non-rendered CSS nodes, normalize Unicode UTS #39 homoglyphs, scan for prompt injection, and turn the stripped hidden ratio into an explicit threat signal."
- **Slide 6 (60s)**: "Our second—and core mathematical—contribution is Dempster-Shafer Evidence Fusion. Instead of `score += 35`, each detector emits a Basic Probability Assignment over `{Malicious, Benign}` and `Theta` (uncertainty). When headers are missing, mass goes to `Theta` instead of causing false positives. When `spf=pass` conflicts with malicious content, the conflict coefficient `K` spikes, immediately flagging compromised-account BEC."
- **Slide 7 (45s)**: "Third, we combine 384-dimensional embeddings in `pgvector` HNSW with a 2-hop heterogeneous Threat Provenance Graph, automatically clustering polymorphic phishing waves in $O(\log N)$ time."
- **Slide 8 (60s)**: "We trained on 14,474 emails from HuggingFace (`zefang-liu/phishing-email-dataset`) and evaluated on 2,000 strictly held-out unseen emails. Under adversarial stress, a pure neural classifier's recall drops from 98.7% to 92.6%, whereas PhishTank-NS achieves **98.95% accuracy, 99.87% recall, and 99.99% ROC-AUC**."
- **Slide 9 (45s)**: "In our multi-slice ablation study covering BEC, CSS poisoning, and homoglyphs, static heuristics get only 42.1% F1 and naive weighted averaging gets 46.2% F1, while PhishTank-NS reaches **100% F1** in **2.93 milliseconds** per email on CPU."
- **Slide 10 (45s)**: "For systems scalability, our concurrent load test achieved **443.12 requests/sec** with **zero errors** and a **21.7 ms median latency**, running entirely on CPU without GPUs, packaged with Docker Compose, Prometheus metrics, GitHub Actions CI, and Render cloud deployment."
- **Slide 11 (45s)**: "Finally, we built a dual-mode React SOC Dashboard: a **Simple View** for non-technical users showing a clear verdict and action plan, and a **Research View** with the interactive 2-hop Threat Graph, Dempster-Shafer interval, and exportable BPA plots—plus a Manifest V3 browser extension for Gmail and Outlook."
- **Slide 12 (30s)**: "In summary, PhishTank-NS bridges adversarial NLP, Dempster-Shafer uncertainty theory, and distributed systems engineering. Thank you—I'm happy to take questions."
